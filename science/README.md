# Scientific account

The project determines how the input and effective output dimensions jointly limit the entanglement-assisted classical-capacity ratio.

1. [Model and exact claims](model.md) defines the capacities, the effective output support, and the affine dimension of the image.
2. [BKM geometry](bkm_geometry.md) develops the quadratic form and its relation to relative entropy.
3. [Output-dimension bound](output_bound.md) combines an information-radius center, an entropy comparison, and an amplification estimate over the output image.
4. [Joint-dimension law](joint-dimensions.md) proves the uniform joint bound, the sharp weak-signal order, and the dimension required for exact local saturation at a maximally mixed replacer.
5. [Weak-signal channels and commuting outputs](sharp_examples.md) gives the exact Clifford-family limit and the distinct linear order for commuting outputs.
6. [Worked channel comparisons](examples.md) compares established channels, the two depolarizing limits, and input padding.
7. [Interpretation](interpretation.md) explains what the scaling implies and what remains open.

The [primary-source comparison](../references/RELATED_WORK.md) records the inherited tools and nearby results. The [finite checks](../verification/README.md) reproduce selected calculations.
